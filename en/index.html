Appointments - 2023

This project is an open-source appointment manager RESTful API built with Node.js, Express.js, JWT, TypeORM, and Typescript. It does have a complete authentication system that includes a role middleware, all data that goes through all endpoints are validated using express-validator. 24 hours before the scheduled date, the user receives an automated email with appointment details; a Cron Job runs every 10 minutes to check the date. All the API endpoints are tested with Jest.

Project's link, get involved.

Library - 2023

Library management system consisting of a REST API developed with Laravel and consumed with Vue.js. It is possible to manage users, books, genres, and loans. All API endpoints are tested using PHPUnit, in addition to the repository design pattern, to make the code more organized, legible, and cleaner. The system also supports multiple languages, including Portuguese and English so far.

Notes - 2021

Note/post-it Management System, this was my first try to use a frontend library to interact with an API. Create, manage, and export your notes in a comprehensive system. I used Laravel for the REST API with JWT authentication on the back end, and Vue.js to make the front end more dynamic, in conjunction with Bootstrap. It includes features for exporting notes to Excel and PDF, logging across all note API endpoints, and a full-featured login system. I also implemented the Repository design pattern and tested all API endpoints using PHPUnit.
